# Эмулятор командной оболочки UNIX

Практическая работа №1 по дисциплине «Конфигурационное управление», вариант 28.

## Общее описание

Консольный эмулятор командной оболочки UNIX. Программа показывает приглашение
в стиле Linux, принимает команды и выводит результат. Приглашение строится из
реальных данных операционной системы: имени пользователя и имени компьютера,
например `student@DESKTOP-01:~$`.

Команды разбираются с учётом кавычек: `ls "my folder"` — это команда и один
аргумент `my folder`.

## Функции и настройки

### Команды

| Команда | Аргументы | Что делает |
|---|---|---|
| `ls` | любые | заглушка: выводит своё имя и аргументы |
| `cd` | 0 или 1 | заглушка: выводит своё имя и аргумент |
| `exit` | нет | выход из эмулятора |

Ошибки выводятся с префиксом `error:`: неизвестная команда, неверное число
аргументов, незакрытая кавычка. После ошибки эмулятор продолжает работу.

## Сборка и запуск тестов

Нужен компилятор C++17.

### Qt Creator

Открыть файл `CMakeLists.txt`, выбрать комплект, собрать проект (Ctrl+B).

### Visual Studio

Файл → Открыть → Папка, выбрать папку проекта. После настройки CMake:
Сборка → Собрать все.

### g++ из командной строки

```
mkdir bin
g++ -std=c++17 -o bin/emulator ^
    src/main.cpp src/parser.cpp src/system_info.cpp src/shell.cpp ^
    src/commands.cpp
```

Во всех случаях программа появляется в папке `bin`.

### Запуск

```
run.bat
```

### Тесты

Тестовые сценарии лежат в папке `tests`. Каждый запускает эмулятор с нужными параметрами:

| Сценарий | Что проверяет |
|---|---|
| `test_repl.bat` | команды из `tests\scripts\repl.txt`: кавычки, заглушки, ошибки, `exit` |

## Примеры использования

```
student@DESKTOP-01:~$ ls
ls: stub called without arguments
student@DESKTOP-01:~$ ls -l "my folder" 'second arg'
ls: stub called [-l] [my folder] [second arg]
student@DESKTOP-01:~$ cd a b
error: cd: too many arguments
student@DESKTOP-01:~$ foo
error: foo: command not found
student@DESKTOP-01:~$ ls "unclosed
error: unclosed quote
student@DESKTOP-01:~$ exit
```

## Структура проекта

```
src/
  main.cpp            точка входа
  parser.h/.cpp       разбор строки на слова с учётом кавычек
  system_info.h/.cpp  данные ОС: пользователь, компьютер
  shell.h/.cpp        приглашение, цикл ввода, выбор команды
  commands.cpp        реализация команд
tests/
  *.bat               тестовые сценарии
  scripts/            стартовые скрипты эмулятора
CMakeLists.txt        сборка через CMake
run.bat               запуск
```
